# 말차요정지도 — Features

2026-09-20 코드 기준. 현재 구현은 코드 확인 결과이며, 전체 기능의 실행 검증 완료를 의미하지 않는다.
기능 변경 시 이 문서의 상태와 동작 규칙을 함께 갱신한다.

## 1. 현재 구현

- 카페 목록·상세, 대표 이미지, 영업시간 등 카페 정보 표시.
- 카페 이름·지역명 부분 검색과 정해진 지역 선택 필터의 조합.
- 다섯 맛 점수 필터와 디카페인·비건·주차·테이크아웃 옵션.
- 검색·필터 결과를 공유하는 목록, 결과 개수, Leaflet 마커.
- 회원가입·로그인, 사용자별 즐겨찾기 추가·제거·목록.
- 리뷰·별점 작성, 조회, 본인 리뷰 삭제.
- 점수 차이를 이용한 취향 추천.
- 비로그인 카페 제보와 관리자 승인·등록·거절.
- 관리자가 지정하는 말차요정 PICK, 운영자 한줄평, 블로그 후기 링크.

관련 코드: [뷰](../cafeapp/views.py), [폼](../cafeapp/forms.py), [URL](../cafeapp/urls.py).

## 2. 검색·필터 규칙

- 국가·도시를 먼저 선택하며 기본은 한국/서울이다. 선택한 도시 안에서 검색·동네·맛·PICK 조건을 적용한다. 도시를 바꾸면 동네 조건만 해제하고 나머지는 유지한다. 초기화는 현재 도시를 유지하고 검색·취향 조건을 해제한다.
- 지도는 선택 도시의 범위를 기본으로 사용하며 결과 좌표가 있으면 해당 결과에 맞춰 이동한다. 결과가 없어도 선택 도시를 보여준다. PICK 마커는 별과 금색 테두리, 팝업 배지로 구분한다.
- 군집화 라이브러리는 아직 추가하지 않았다. 이번 단계는 도시 단위 조회와 기존 Leaflet 마커를 유지한다.

- `q`: 앞뒤 공백을 제거하고 카페 이름 또는 지역명에 포함되는 카페를 검색한다. 지역 버튼·맛·옵션 조건과는 AND로 함께 적용한다.
- `area`: 삼성·성수·명동·연남·서촌·삼청 중 선택값을 정확 일치로 검색한다. 목록 밖의 값은 지역 필터를 적용하지 않는다.
- 검색어와 지역, 유효한 맛·옵션 조건은 함께 적용한다.
- `pick=1`이면 말차요정 PICK 카페만 표시하며 이름·지역·맛·옵션 조건과 함께 적용한다. 최종 결과는 카드·결과 수·지도 마커에 동일하게 사용한다.

| 맛 점수 항목 | 필터 조건 |
|---|---|
| 진하기 `matcha_strength` | 선택값 이상 |
| 쌉싸름함 `bitterness` | 선택값 이상 |
| 단맛 `sweetness` | 선택값 이하 |
| 우유맛 `milkiness` | 선택값 이하 |
| 말차 향 `matcha_aroma` | 선택값 이상 |

각 맛 입력은 1~5이며 선택하지 않은 항목은 제한하지 않는다.
선택한 항목의 점수가 없는 카페는 그 조건에서 제외된다.
추가 옵션은 체크한 항목만 True 조건으로 제한한다.
현재 맛 필터 폼이 유효하지 않으면 맛·옵션 필터 전체를 적용하지 않고 이름·지역 조건만 적용한다.

지도는 같은 검색 결과 중 위도·경도가 모두 있는 카페만 표시한다.
좌표 없는 카페도 카드와 결과 개수에는 포함된다. 마커 팝업은 대표 사진·이름·지역·메뉴·가격·평균 평점·리뷰 수·상세 링크를 표시한다. 사진 미등록 또는 로딩 실패 시 대체 영역, 리뷰가 없으면 안내 문구를 표시한다.
조건을 제출해 페이지가 갱신되는 방식이며 입력 즉시 비동기로 갱신하는 기능으로 설명하지 않는다.

## 3. 취향 추천 규칙

- 다섯 가지 원하는 맛 점수(각 1~5)를 모두 입력한다.
- 다섯 맛 점수가 모두 있는 카페만 대상으로 하며, 체크한 필수 옵션을 먼저 적용한다.
- 각 항목의 절대 차이를 합산하고 합이 작은 순서로 최대 3곳을 추천한다.
- 동점이면 카페 ID 오름차순이다.
- 표시 일치율은 `round((1 - 차이의 합 / 20) * 100)`이다.
- 현재 추천에는 지역·이름 검색 조건이 없다.

현재 기능은 점수 기반 계산이다. 자연어 해석, 외부 AI 모델, 사용자 취향 저장은 이 기능에 포함되지 않는다.

## 4. 리뷰·즐겨찾기·제보 규칙

- 리뷰와 즐겨찾기 변경은 로그인이 필요하고 POST 요청으로 수행한다.
- 리뷰는 사용자당 카페별 1개, 별점 1~5점, 한줄평 최대 200자이며 본인만 삭제할 수 있다.
- 즐겨찾기는 사용자·카페 조합당 1개이며 다시 누르면 제거한다.
- 제보는 로그인 없이 제출하고 pending으로 저장한다.
- 관리자 승인 상태 변경과 Cafe 등록은 별도 작업이다. 자세한 제약은 [DATA_MODEL](DATA_MODEL.md)을 참고한다.

## 5. 다음 개선 후보

- 3단계 맛 표현을 채택할 경우 점수·검색 조건 대응 확정.
- 즐겨찾기 개수 표시 등 사용성 개선.
- 초기화 시 검색어·지역을 유지할지 명확한 정책 결정.

이미 있는 필터·리뷰·즐겨찾기를 새로 구현하는 작업으로 취급하지 않는다.

- 카페별 인기 메뉴·메뉴 사진·태그.
- 사용자 취향 저장, 최근 본 카페, 방문 체크.
- 인기순·평점순·거리순·가격순 정렬.
- 자연어 취향 검색, 리뷰 요약 등 AI 기능. 일반 검색·필터를 유지하며 실제 AI 기능과 점수 기반 추천을 구분한다.
- 국가·도시 선택, 다국어 카페 이름, 현지 통화, 국가별 주소 형식, 사용자 언어 기능 확장.

미래 후보는 이번 작업의 구현 지시가 아니다. 기존 기능 안정성, 탐색 편의, 말차 특화 가치, 모바일 사용성 순으로 작업 우선순위를 판단한다.

## 관리자 대표 사진 관리

`/admin/cafeapp/cafe/`에서 카페를 선택하고 ‘대표 사진’ 영역에서 파일을 등록·교체·제거한 뒤 저장한다. 목록 썸네일과 현재 사진 미리보기를 제공한다. 저장된 사진은 메인 카드와 상세 페이지에서 사용한다. 메인의 ‘사진 편집’ 링크는 카페 변경 권한이 있는 직원 계정에만 표시된다. 사진 자르기·보정 기능은 포함하지 않는다.

## Hero 배너 관리 (2026-09-21)

관리자 → 메인 Hero 배너에서 사이트 전체 대표 이미지를 등록·교체·삭제한다. 저장된 이미지 미리보기와 가운데/왼쪽/오른쪽 정렬을 제공한다. 이미지가 없으면 기존 일러스트를 사용한다. 가로형 이미지에 object-fit: cover를 적용하며 모바일에서는 문구 아래에 표시한다. 카페 사진과 별도로 관리한다.

## 메인 취향 필터 UI (2026-09-21)

메인의 진하기·쌉싸름함·단맛·말차 향 필터는 슬라이더와 드롭다운 대신 3단계 선택 버튼으로 표시한다. 서버의 기존 이상·이하 필터 계산은 유지하며, 진하기·쌉싸름함·말차 향의 단계는 `1 / 3 / 4`, 단맛의 단계는 `2 / 3 / 5`를 전달한다. 우유맛은 메인 필터 패널에는 표시하지 않지만 기존 데이터 필드와 서버 필터 로직, 취향 추천 기능은 유지한다. 추가 옵션은 기존 Boolean 값을 전송하는 선택형 칩으로 표시한다. 전체 초기화는 모든 검색 조건을 지우고 기본 목록으로 돌아간다.
