CSV로 카페 일괄 등록

아래 열(컬럼) 이름을 그대로 써서 CSV 파일을 만들어주세요. 첫 줄은 반드시 열 이름이어야 합니다.

예시 CSV 파일 내려받기

열 이름 필수 여부 설명
name필수카페 이름
area필수지역 (예: 성수, 연남 등)
address필수주소
menu_name필수대표 메뉴
price필수가격 (숫자만)
description필수카페 설명
business_hours선택영업시간
latitude / longitude선택위도 / 경도 (비워두면 지도에 안 뜸)
matcha_strength / bitterness / sweetness / milkiness / matcha_aroma선택1~5 점수, 비워두면 미입력 처리
is_decaf / is_vegan / has_parking / has_takeout선택1 또는 0 (참/거짓)
is_matchayojung_pick선택1 또는 0 (말차요정 PICK 여부)
